How the value is modelled

—

Each category is priced off its own token-bearing peers: the median market-cap / TVL of the tokens that already trade in that category. A category with fewer than three peers falls back to the market-wide median. Growth and age adjust the multiple; no protocol name is ever special-cased. An implied value is this radar's own claim, never a prediction that a token will launch, or when.
